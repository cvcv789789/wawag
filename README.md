# 刮紙辨識 V1 - GitHub Pages 測試版

## 最快上線方式

1. 登入 GitHub
2. 建立一個新的 Repository，例如：
   scratchcard-v1
3. 把這個資料夾裡的 `index.html` 上傳到 Repository 根目錄
4. 到：
   Settings → Pages
5. 在「Build and deployment」選：
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
6. 按 Save
7. 等約 1～3 分鐘
8. GitHub 會顯示你的網址，通常像：
   https://你的帳號.github.io/scratchcard-v1/

## 手機操作

1. 用 iPhone Safari / Android Chrome 開網址
2. 選：
   - 📷 直接拍照
   - 🖼️ 從相簿選擇
3. 輸入完整刮數，例如 60
4. 雙指縮放、單指拖曳照片
5. 把一個完整未刮黑圈移到中央黃色準星
6. 按「設定未刮樣本」
7. 按「開始辨識」

## 注意

- 這是 V1 測試版，主要先確認手機操作與樣本選取能正常執行。
- 若要提高辨識準確率，下一版可以再針對你的實際刮紙版型微調。

🎯 娃娃機刮刮樂｜剩餘洞數辨識系統

這是一個用來協助辨識 刮刮紙剩餘未刮數量 的網頁工具。

主要使用情境是娃娃機、彈珠台、抽獎活動等使用「刮號碼 / 刮洞」玩法的店家，可以透過手機或電腦上傳刮紙照片，讓系統協助判斷目前還有多少格尚未刮開。

✨ 主要功能
📷 支援上傳照片
📱 手機、電腦皆可使用
🔢 可自行設定完整刮紙總格數
↔️ 可設定每列格數
🎯 自行選擇完整「未刮膜」作為辨識樣本
🔍 局部位置修正，處理刮膜位置偏移
💡 反光容忍度調整
⭕ 支援圓形刮膜辨識
⬛ 支援方形刮膜辨識
📊 自動統計未刮 / 已刮數量
🚀 使用方式
1. 上傳刮紙照片

使用手機拍照或從電腦選擇刮紙圖片。

建議：

照片盡量清楚
避免嚴重反光
刮紙盡量攤平
拍攝角度盡量正面
2. 輸入刮紙設定

例如一張完整刮紙：

完整格數：60
每列格數：10

系統就會依照設定分析整張刮紙。

3. 選擇未刮樣本

選擇照片中一個 完整、尚未刮開的刮膜 作為樣本。

樣本選得越完整、越清楚，通常辨識效果越好。

4. 設定局部位置修正

局部位置修正是為了處理每一格刮膜位置不完全一致的問題。

例如：

±5% → 小範圍搜尋
±10% → 中等搜尋
±15% → 較大範圍搜尋

如果照片很正、刮膜排列整齊，可以使用較小數值。

如果照片有角度、紙張彎曲或刮膜位置偏移，可以提高搜尋範圍。

5. 開始辨識

系統會分析每一格，最後顯示：

完整格數
偵測格數
未刮數量
已刮數量
⚠️ 辨識並非 100% 準確

這個工具目前仍屬於實驗 / 測試性質。

辨識結果可能受到以下因素影響：

拍攝角度
燈光反光
紙張彎曲
照片模糊
刮膜沒有刮乾淨
不同刮紙的印刷方式
刮膜形狀、大小不同
刮膜位置偏移

因此目前建議把辨識結果當作 輔助判斷，重要情況仍建議人工確認。

🧪 開發說明

這個專案經過多個版本持續測試與修改。

目前主要方向是改善：

不同拍攝角度造成的誤差
刮紙透視變形
圓形 / 方形刮膜辨識
已刮但沒有刮乾淨造成的誤判
每格刮膜位置不同造成的辨識偏差
反光造成的辨識問題

目前測試下來，V1.3.9 系列的辨識方式相對穩定，因此後續版本主要會以此架構繼續改善。

# V1.3.9P3 自適應局部修正版

基於 V1.3.9P2，保留：
- V1.3.9 核心辨識
- 四角透視校正
- 破膜檢測
- 反光容忍度

這次只修改「局部位置修正」。

## 新邏輯
假設上限設定 15%：

1. 每一格先搜尋 ±5%
2. 如果找到高可信的完整未刮膜，立即停止
3. 信心不足才擴大到 ±10%
4. 仍不足才擴大到 ±15%

因此不是所有格子都直接使用 ±15%。

## 好處
- 原本 ±5% 就準的格子不容易被大範圍搜尋帶偏
- 真的因紙張彎曲、透視或局部印刷偏移的格子，才會擴大到 10% / 15%
- 每格仍限制在自己的邏輯格內

建議：
- 自動局部修正上限：15%
- 反光容忍度：先維持你目前測試最穩的設定
